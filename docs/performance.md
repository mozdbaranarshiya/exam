# بهبود سرعت و ظاهر

رابط فارسی با فونت محلی Vazirmatn، پنل معلم، کارت‌های آمار، فرم‌های خوانا و
نمای موبایل بازطراحی شده است. سایت همچنان بدون وابستگی تولیدی یا مرحله build
روی GitHub Pages اجرا می‌شود. فونت و آیکون از خود سایت بارگیری می‌شوند.

پس از ثبت نمره، پاسخ همان RPC جمع نمره و وضعیت دانش‌آموز را به‌روز می‌کند؛
همه پاسخ‌ها دوباره دریافت نمی‌شوند و فرم باز می‌ماند. اطلاعات پنل و نمرات تا
۱۵ ثانیه فقط در حافظه همان زبانه نگهداری می‌شوند. خروج یا تغییر حساب، این
حافظه را پاک می‌کند. دکمه «به‌روزرسانی» اطلاعات تازه سرور را دریافت می‌کند.
درخواست‌های هم‌زمان یکسان نیز فقط یک بار ارسال می‌شوند. پاسخ‌های دانش‌آموز
تا بازکردن کارنامه او، به عنصرهای صفحه تبدیل نمی‌شوند.

## مقایسه کنترل‌شده مرورگر

نسخه اولیه commit `a0499dd` با نسخه جدید، در سه اجرای مرورگر و با ۵۰
دانش‌آموز، ۲۰ سؤال و تأخیر ثابت ۱۵۰ میلی‌ثانیه برای هر RPC مقایسه شد.
این زمان‌ها میانه آزمایش محلی‌اند و اندازه‌گیری اینترنت یا سایت تولیدی نیستند.

| کار | قبل | بعد |
| --- | --- | --- |
| ثبت نمره و نمایش نتیجه | ۸۴۳ میلی‌ثانیه، ۲ درخواست | ۲۱۷ میلی‌ثانیه، ۱ درخواست |
| بازگشت به پنل تازه | ۲۰۳ میلی‌ثانیه، ۱ درخواست | ۳۶ میلی‌ثانیه، بدون درخواست |
| بازگشت به نمرات تازه | ۲۴۵ میلی‌ثانیه، ۱ درخواست | ۶۳ میلی‌ثانیه، بدون درخواست |
| عنصرهای پاسخ در کارنامه‌های بسته | ۱۰۰۰ | صفر |

در این سناریو، زمان ثبت نمره حدود ۷۴٪ کاهش یافت. بازکردن کارنامه هر دانش‌آموز
همچنان پاسخ‌های او را نمایش می‌دهد؛ آزمون مرورگر حفظ نمره، فرم باز، دریافت
تغییرات از طریق به‌روزرسانی و جداسازی حافظه حساب دو معلم را بررسی می‌کند.

برای تکرار مقایسه، نسخه اولیه را در پوشه جدا از مخزن جاری قرار دهید:

```sh
EXAM_BROWSER_TOOLS=/workspace/.exam-tools \
EXAM_BROWSER_EXECUTABLE=/usr/bin/chromium \
EXAM_BENCHMARK_BASELINE=/tmp/exam-baseline-a0499dd/exam \
node tests/performance-browser.mjs
```

آزمون سرعت از پاسخ‌های شبیه‌سازی‌شده استفاده می‌کند و داده واقعی معلمان را
نمی‌خواند. آزمون‌های اتصال واقعی، جداگانه در `scripts/live-smoke.py` و
`tests/live-browser.mjs` اجرا می‌شوند.
