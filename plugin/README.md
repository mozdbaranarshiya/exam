# افزونه آزمون‌ساز، نسخه ۰٫۲٫۰

نسخه مهاجرت‌شده اولیه فقط متن Skill داشت. نام‌های `createExam` و
`getExamResults` در آن متن ابزار قابل اجرا ایجاد نمی‌کردند. این نسخه همان
شناسه افزونه را نگه می‌دارد و یک راهنمای اجرایی و کلاینت Python همراه دارد
تا در محیط Codex دارای ابزار اجرا، به API واقعی متصل شود. ثبت یا تغییر نمره
پاسخ تشریحی نیز از داخل افزونه امکان‌پذیر است؛ تست‌ها خودکار تصحیح می‌شوند.

## دریافت و نصب نسخه جدید

۱. فایل `downloads/exam-plugin-0.2.0.zip` را از مخزن دانلود کنید.

۲. در ChatGPT، صفحه Plugins → «آزمون‌ساز معلمان» را باز کنید. از منوی افزونه
یا Edit plugin گزینه **Upload new version** را بزنید و همین ZIP را انتخاب کنید.
خود فایل ZIP را بارگذاری کنید؛ استخراج لازم نیست. پس از تأیید نسخه، آن را
در یک گفت‌وگوی جدید فراخوانی کنید.

۳. در سامانه، وارد حساب معلم شوید و از «اتصال به ChatGPT» کلید اختصاصی بسازید.
آن را فقط در تنظیمات امن **محیط اجرای Codex** با نام `EXAM_TEACHER_TOKEN`
ذخیره کنید و تنظیمات را اعمال کنید. کلید را در چت، متن افزونه، فایل مخزن یا
تنظیمات عمومی قرار ندهید. هر معلم به کلید و محیط شخصی خودش نیاز دارد.

۴. محیط باید Python 3.10 یا جدیدتر، ابزار اجرای فرمان و دسترسی HTTPS به
`pukanizbahswrupscfmg.supabase.co` داشته باشد. انتقال تنظیمات API Key یک GPT
به این افزونه خودکار نیست. یک محیط بدون ابزار اجرا یا بدون کلید شخصی نمی‌تواند
با این نسخه داده بخواند؛ بسته حاضر MCP Server یا رابط OAuth نیست.

۵. افزونه را در چت فراخوانی کنید و بگویید: «آزمون ریاضی با یک سؤال تستی
۲+۲، چهار گزینه ۱ تا ۴، پاسخ صحیح ۴ و بارم ۲ بساز.» پاسخ باید لینک واقعی
API را شامل شود. بعد از ثبت پاسخ دانش‌آموز، گزارش نمرات همان ID را بخواهید.
نمره تشریحی تصحیح‌نشده موقت است.

۶. برای ثبت نمره تشریحی، نام دانش‌آموز، سؤال و نمره دقیق را مشخص کنید؛ مثلاً
«در آزمون [ID]، نمره پاسخ تشریحی سؤال دوم علی رضایی را ۲٫۵ از ۳ ثبت کن.»
افزونه ابتدا پاسخ ذخیره‌شده و بارم را می‌خواند و پس از ثبت موفق، نمره واقعی
را اعلام می‌کند. برای تصحیح توسط دستیار، معیار تصحیح را نیز مشخص کنید.
اگر کلید قدیمی مجوز `grade:essay` ندارد، در سایت کلید جدید بسازید و آن را
در تنظیمات امن محیط جایگزین کنید؛ دسترسی شخصی هر معلم محفوظ می‌ماند.

ZIP فعلاً مطابق درخواست صاحب پروژه در GitHub می‌ماند؛ آن را بدون درخواست
بعدی حذف نکنید. این فایل هیچ کلید اختصاصی معلم یا توکن مدیریتی ندارد.

## ساخت و بررسی بسته

```sh
python3 scripts/build-plugin.py
python3 tests/plugin_test.py
```

آرشیو با فهرست دقیق فایل‌ها و ترتیب/تاریخ ثابت ساخته می‌شود. ریشه ZIP مستقیماً
`.codex-plugin/plugin.json` و `skills/` است. فایل‌های محیط، مستندات توسعه و
فایل ZIP در ZIP قرار نمی‌گیرند. فیلدهای مانیفست از قالب افزونه آپلودشده حفظ
شده‌اند؛ قابلیت یا ابزار پلتفرمی تأییدنشده به آن افزوده نشده است.

کلاینت HTTPS فقط ساخت آزمون، خواندن نتایج و ثبت نمره تشریحی را می‌پذیرد؛ تغییر میزبان از CLI
ممکن نیست، تغییر مسیر HTTP پذیرفته نمی‌شود و بررسی گواهی TLS فعال است.
کلید فقط از محیط خوانده می‌شود؛ قالب مبهم جایگزین‌های امن پراکسی مجاز است.
خطاها شامل مقدار کلید، هدر درخواست یا متن خام خطای شبکه نیستند.
